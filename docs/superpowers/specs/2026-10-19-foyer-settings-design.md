# Foyer 0.5 settings

The approved release adds Manage Home, appearance settings, and named HDMI tiles. It stays a native, offline Java Android TV launcher with API 23 minimum / target 34, no new permissions or runtime dependencies, and the same package/signing key and MIT licence. No launcher activation or system input settings change is part of this release.

A new Foyer settings utility opens a private landscape SettingsActivity. TV Settings remains a separate utility. All controls work through D-pad, OK and Back with visible focus. Back returns from a settings section to the settings menu, then Home. Home can leave settings through the existing launcher path. Settings apply immediately and survive process restart. Existing order, hidden choices, appearance defaults, and both Sony Home mechanisms are preserved.

Manage Home lists discovered launchable apps with icons and checkboxes, visible apps first in saved order. Play Store and Android TV Settings retain utility treatment. Move up/down changes visible Home order without unhiding other apps. A single Undo removal action restores the last removed app at its previous position, including removal through the existing Home long-press menu. Empty Home remains valid with All apps and Foyer settings available. App discovery is shared with Home to prevent drift; installed/removed packages are reconciled when the screen resumes. Existing long-press actions remain available.

Appearance offers Auto (existing layout), Small, Medium, Large tile sizes; Compact, Normal, Spacious spacing; original gradient, charcoal and black backgrounds; always-visible app labels; date and clock toggles. A Minimal preset selects large tiles, black background, labels on and date/clock off. Restore defaults changes only appearance. Layout columns adapt to tile width and spacing so all tiles stay within the screen, with scrolling for additional rows. Main Home and All apps both use these layout choices. Default Auto/Normal preserves the old layout.

Inputs lists the standard visible hardware HDMI inputs supplied by the TV, keyed by stable input ID rather than port label. A Foyer-only name, four outline icon choices (HDMI, TV, media box, game), visibility and move controls are saved locally. Blank names restore the TV label; whitespace-only input is trimmed; names are limited to 40 characters. The Home utility row shows the first four visible HDMI inputs in the user's order. Hiding every input does not trigger an unwanted native Inputs fallback; that fallback appears only when the TV provides no eligible standard inputs. Disconnect/reconnect keeps customizations; settings cannot invent missing input registrations. Original passthrough IDs remain the launch targets.

Builder choices: a separate native settings activity, shared Android discovery/preferences helper, and a small pure Java appearance/layout model. No account, backup, first-run flow, household layout or ambient screen is included. Test model boundaries on the JVM, preserve install/recovery regressions, then check settings, persistence, focus, app order and Home on the Android 12 and 14 Sony TVs. Export APK/metadata and public source ZIP; no commit/push without the user's separate approval.
